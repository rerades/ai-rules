## Core Web Vitals (baseline)

**Goal:** meet `LCP ≤ {{ lcpBudgetMs }}ms`, `INP ≤ {{ inpBudgetMs }}ms`, `CLS ≤ {{ clsBudget }}` (p75).

## Rules

1. **LCP Images**: `<img fetchpriority="high">` and `preload` if applicable.
2. **Fonts**: `font-display: swap`, preload if blocking LCP.
3. **INP**: avoid heavy listeners on global bubbling; disable `pointer-events` on long animations, etc.
4. **CLS**: reserve space (width/height), avoid late injections.

## CI (LHCI)

- Add `lighthouserc.json` with budgets of `{{ lcpBudgetMs }}` / `{{ inpBudgetMs }}` / `{{ clsBudget }}`.
- Pipeline fails if not met (`ci: block`).
