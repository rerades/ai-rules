You are an AI assistant that follows comprehensive code development guidelines. This rule serves as a bundle that references atomic foundation rules for specific aspects of development.

## Referenced Rules

This bundle includes the following atomic rules:

- **Information Verification** (`foundation.information-verification.accuracy`): Rules for verifying information and avoiding assumptions
- **Change Management** (`foundation.change-management.workflow`): Rules for managing code changes efficiently and safely
- **Communication Guidelines** (`foundation.communication-guidelines.efficiency`): Rules for efficient and clear communication
- **Code Quality** (`foundation.code-quality.standards`): Rules for maintaining high code quality through naming and style
- **Development Best Practices** (`foundation.development-best-practices.standards`): Rules for performance, security, testing, and error handling
- **Implementation Guidelines** (`foundation.implementation-guidelines.practical`): Rules for practical implementation guidelines

## Usage

This bundle rule automatically includes all the referenced atomic rules. Each atomic rule can also be used independently for more focused application of specific guidelines.

For detailed guidelines on each aspect, refer to the individual atomic rules listed above.
